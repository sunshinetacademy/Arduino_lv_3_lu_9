بنينا حارس غرفة متكامل فيه PIR + RTC + BME280 + OLED + Buzzer — يعمل بمفرده في الغرفة.

💭 فكّر:

الحارس يشتغل محلياً. لو أردت رؤية حالة الغرفة من الموبايل — أو تشغيل/إطفاء شيء من غرفة أخرى... كيف؟

🔮

توقّع أولاً

كيف يمكن لـ ESP32 أن يستقبل أوامر من موبايل — بدون تطبيق، وبدون اشتراك في خدمة؟

✅ الإجابة:

Web Server (سيرفر ويب)! ESP32 نفسه يصبح صفحة ويب. تفتح موبايلك، تكتب عنوان IP على نفس شبكة الواي فاي، فتظهر لك صفحة ويب تتحكم فيها كل شيء.

الجميل: لا تحتاج تطبيق، لا حساب، لا اشتراك. مجرد متصفح + IP + شبكة واحدة. هذا ما يعنيه Client-Server.

في المشاريع الكبيرة: سنستخدم لاحقاً منصات مثل Blynk (L3-09) للتحكم من أي مكان في العالم. لكن نبدأ بالأساس: كيف يعمل Web Server!

📍

IP Address

العنوان الرقمي لجهازك على الشبكة. مثل: 192.168.1.45

🚪

Port

رقم "الباب" الذي يدخل منه الطلب. Web Server يستخدم 80 دائماً.

📨

HTTP

اللغة المشتركة. GET لطلب صفحة، POST لإرسال بيانات.

🎯 التشبيه الكامل: تخيّل ESP32 مطعماً. الموبايل = الزبون الذي يدخل من الباب رقم 80 (Port)، يقول العنوان 192.168.1.45 (IP)، يطلب طبقاً محدداً (GET /led/on)، والمطبخ يرد بالطبق جاهزاً (Response مع الصفحة).

🔬 رحلة الطلب — 4 مراحل

04 / 11
1
ESP32 يتصل بالواي فاي — يحصل على IP من الراوتر (مثل الموبايل).
2
ESP32 يشغّل WebServer على Port 80 — يبدأ الاستماع للطلبات.
3
الموبايل يفتح IP في المتصفح — يرسل GET / إلى ESP32.
4
ESP32 يرد بصفحة HTML — المتصفح يعرضها، المستخدم يضغط أزراراً.
📱 مثال المتصفح يرسل: 
GET /led/on HTTP/1.1
Host: 192.168.1.45
User-Agent: Chrome
🧠 ESP32 يرد: 
HTTP/1.1 200 OK
Content-Type: text/html

<html><body>LED is ON</body></html>
⚠️ حقيقة مهمة: ESP32 و الموبايل لازم يكونوا على نفس شبكة الواي فاي. لو الموبايل على 4G، مش هيقدر يشوف ESP32 لأنه على IP محلي (داخلي).
⚠️ تحذير حرج

🛡️ 3 قواعد أمان

05 / 11
⚡ تحذير 1 — لا تعرضه على الإنترنت:

Web Server على ESP32 بدون حماية (لا كلمة سر، لا تشفير). لا تعرضه على الإنترنت مباشرة — أي شخص يقدر يتحكم في جهازك. اجعله على شبكة محلية فقط.

⚠️ تحذير 2 — كلمة سر الواي فاي:

لا تضع كلمة السر في الكود الذي تشاركه على GitHub. استخدم ملف secrets.h منفصل + أضفه إلى .gitignore.

⚠️ تحذير 3 — الشبكة العامة:

لا تشغّل ESP32 على شبكة عامة (مقهى، مطار). أي شخص على نفس الشبكة يستطيع أن يفتح IP ويضغط الأزرار.

💡 مستقبلاً في L3-09 (Blynk): سنستخدم منصة سحابية آمنة (Blynk) تتولى الحماية والتحكم من أي مكان — بدلاً من Web Server مكشوف. هذا هو الحل الاحترافي.

خطوة 3

افتح Serial Monitor → خُذ IP → افتحه في متصفح موبايلك.

🔍 خطوات التشغيل:

1. وصّل الموبايل بنفس شبكة الواي فاي التي يستخدمها ESP32.

2. ارفع الكود إلى ESP32.

3. افتح Serial Monitor بسرعة 115200 — سترى IP: 192.168.x.x.

4. افتح هذا العنوان في متصفح الموبايل.

5. تظهر لك صفحة الويب — اضغط الأزرار للتحكم!

⚠️ مشكلة شائعة: لو الصفحة لا تفتح، تحقق من: • الموبايل على نفس الشبكة • الـ IP صحيح • ESP32 ما زال متصلاً (شاهد Serial) • جرّب جهازاً آخر.

🧪 الكود 1: تشغيل/إطفاء LED

07 / 11

أبسط تطبيق: صفحة ويب فيها رابط "LED ON" و"LED OFF". هذا أساس كل شيء في Web Server.

#include <WiFi.h>
#include <WebServer.h>

const char* SSID     = "YourWiFiName";
const char* PASSWORD = "YourPassword";
const int   LED_PIN  = 2;  // LED مدمج

WebServer server(80);  // Port 80

// ─── صفحة الويب ───
String buildPage() {
  String html = "<!DOCTYPE html><html><head>";
  html += "<meta charset='UTF-8'>";
  html += "<meta name='viewport' content='width=device-width,initial-scale=1'>";
  html += "<title>ESP32 Control</title></head><body>";
  html += "<h1>ESP32 LED Control</h1>";
  html += "<p><a href='/led/on'>🔆 LED ON</a></p>";
  html += "<p><a href='/led/off'>🌑 LED OFF</a></p>";
  html += "</body></html>";
  return html;
}

// ─── معالجات المسارات ───
void handleRoot() {
  server.send(200, "text/html", buildPage());
}

void handleLedOn() {
  digitalWrite(LED_PIN, HIGH);
  server.send(200, "text/html",
    "<h1>LED is ON 🔆</h1><a href='/'>Back</a>");
}

void handleLedOff() {
  digitalWrite(LED_PIN, LOW);
  server.send(200, "text/html",
    "<h1>LED is OFF 🌑</h1><a href='/'>Back</a>");
}

// ─── Setup ───
void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);

  WiFi.begin(SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) delay(500);

  Serial.print("Open: http://");
  Serial.println(WiFi.localIP());

  // تسجيل المسارات (Routes)
  server.on("/",        handleRoot);
  server.on("/led/on",  handleLedOn);
  server.on("/led/off", handleLedOff);

  server.begin();
  Serial.println("Server started");
}

void loop() {
  server.handleClient();  // ← الأهم: الاستماع للطلبات
}
🎯 3 أفكار مفتاحية:

server.on("/path", handler) — يربط مساراً بدالة.
server.send(code, type, body) — يرسل الرد.
server.handleClient() — يجب استدعاؤها في loop دائماً.

// ─── Handlers ───
void handleRoot() {
  server.send_P(200, "text/html", PAGE_HTML);
}

void handleLedOn() {
  digitalWrite(LED_PIN, HIGH);
  ledState = true;
  server.send(200, "text/plain", "on");
}

void handleLedOff() {
  digitalWrite(LED_PIN, LOW);
  ledState = false;
  server.send(200, "text/plain", "off");
}

// ─── بيانات JSON للحساس ───
void handleData() {
  float temp = temperatureRead();  // حساس داخلي
  String json = "{\"temp\":" + String(temp, 1);
  json += ",\"led\":" + String(ledState ? "true" : "false") + "}";
  server.send(200, "application/json", json);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);

  WiFi.begin(SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) delay(500);

  Serial.print("Open: http://");
  Serial.println(WiFi.localIP());

  server.on("/",        handleRoot);
  server.on("/led/on",  handleLedOn);
  server.on("/led/off", handleLedOff);
  server.on("/data",    handleData);

  server.begin();
}

void loop() {
  server.handleClient();
}
🎯 3 نقاط ذكية:

PROGMEM + R"HTML(...)HTML" — يخزن HTML في Flash بدلاً من RAM.
fetch('/data') في JavaScript — يطلب البيانات كـ JSON كل ثانيتين.
server.send_P() — يرسل نصاً من Flash (أسرع، يوفّر RAM).
